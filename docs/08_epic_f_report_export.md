# Title
Epic F: Report Export (Reproducible Portfolio Artifact)

## Objective
Generate a reproducible PDF report that captures the complete workflow:
- Data summary and QC
- Planning results (target line and DLS)
- Correlation panel with picks
- Simulation decisions and interpretation evolution
- KPI summary

The report is the primary portfolio deliverable.

## Functional requirements
### P0
- One-click "Export report" produces a PDF file in `exports/`
- Report includes:
  1) Project summary: wells loaded, curves available, QC warnings
  2) Pre-spud plan section:
     - plan inputs
     - plan plots (MD vs TVD, DLS vs MD)
     - DLS exceedance table
  3) Correlation section:
     - correlation panel snapshot (image)
     - marker list table (per well or consolidated)
  4) Steering section:
     - decision log table
     - KPI summary (percent in zone, avg distance)
     - final interpretation summary (control points)
  5) Appendix:
     - assumptions and disclaimers

### P1
- Embed per-step snapshots (selected steps)
- Export report as HTML as well

### P2
- Export a "data package" zip containing project JSON + exports

## Reproducibility requirements
- Report content must be reproducible from saved project state:
  - same plots, same tables, same KPI numbers
- Avoid using current timestamps inside the report body unless explicitly allowed in a header field.

## Implementation guidance
- Use a deterministic plotting pipeline:
  - Render plots to PNG with fixed figure size
  - Embed images into PDF
- PDF generation options:
  - WeasyPrint (HTML to PDF) or ReportLab
  - Choose one and standardize.

## Inputs
- Project state from disk:
  - plan artifacts
  - marker sets
  - decision logs
  - interpretation versions
  - KPI summary values
- Snapshot images generated by UI or by a headless plot function

## Acceptance tests
### Test F1: Report generation without UI
Given a saved project directory
When running `python -m app.export_report <project_path>`
Then a PDF is created
And it contains expected section headers and non-empty tables

### Test F2: Deterministic report hash (optional strict)
Given stable inputs and plot settings
When generating report twice
Then PDF file hash matches (or matches after normalizing metadata)

## Definition of Done
- Report export works reliably and is usable as a portfolio artifact
- Report can be generated via CLI for CI validation
