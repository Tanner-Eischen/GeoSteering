# Geosteering Workbench MVP: Fine-Grained Implementation Plan (Backlog)

This folder contains a fine-grained task and subtask implementation plan, organized as GitHub-issue-style specs, and explicitly traceable to the spec documents in the original MVP zip.

## How to use
- Treat each `M*-*.md` file as a milestone backlog.
- Each task is formatted so it can be copied directly into a GitHub Issue.
- Use the task IDs (e.g., `M5-SIM-400`) as stable identifiers across commits and PRs.
